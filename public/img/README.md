# Папка изображений

Положите сюда реальные файлы, на которые ссылаются `src/pages/Home.tsx`
(`avatar.png`) и `src/data/media.ts` (обложки манги/аниме).

Пока файлов нет — компоненты используют `onError`, чтобы вместо
битой картинки автоматически показать плейсхолдер через
[placehold.co](https://placehold.co), так что сайт не сломается даже
без реальных изображений.

Рекомендуемый вес: до ~300 КБ на файл (JPG/WebP для фото, PNG для
обложек с прозрачностью). Большие исходники (RAW, PSD) в репозиторий
не кладите — GitHub не предназначен для хранения тяжёлых бинарников
без Git LFS.
