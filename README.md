# Артём Тыщенко — личный сайт

Личная страница-визитка: подборка видео, коллекция манги/аниме и форма для
предложений о сотрудничестве. Переписана с чистого HTML/CSS/JS на
**React + TypeScript + Vite** с несколькими страницами через `react-router-dom`.

🔗 Демо: _добавьте сюда ссылку после деплоя на GitHub Pages_

## Стек

- [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/) — сборка и dev-сервер
- [React Router](https://reactrouter.com/) — переключение между страницами без перезагрузки
- Чистый CSS (без препроцессоров), стили вынесены в `src/styles/global.css`

## Страницы

| Маршрут     | Страница                              |
|-------------|----------------------------------------|
| `/`         | Главная (аватар, соцсети)              |
| `/videos`   | Видеоплеер с избранными роликами       |
| `/gallery`  | Коллекция манги/аниме с фильтром и модальным окном |
| `/contact`  | Форма для предложений о сотрудничестве |

## Быстрый старт

```bash
git clone https://github.com/Artyom-Tyshchenko/<repo-name>.git
cd <repo-name>
npm install
npm run dev
```

Откройте `http://localhost:5173`.

### Сборка для продакшена

```bash
npm run build   # результат в папке dist/
npm run preview # локальный просмотр собранной версии
```

## Структура проекта

```
├── public/img/          # статичные изображения (аватар, обложки)
├── src/
│   ├── components/       # переиспользуемые UI-компоненты (Navbar, Footer...)
│   ├── data/              # контент вынесен из разметки: videos.ts, media.ts
│   ├── pages/             # страницы, подключённые к роутеру
│   ├── styles/            # global.css
│   ├── App.tsx            # маршрутизация
│   └── main.tsx           # точка входа
├── .github/workflows/    # автодеплой на GitHub Pages
└── vite.config.ts
```

Чтобы добавить видео или тайтл манги/аниме, не нужно трогать разметку —
достаточно добавить объект в `src/data/videos.ts` или `src/data/media.ts`.

## Деплой на GitHub Pages

В репозитории уже настроен workflow `.github/workflows/deploy.yml`: при пуше
в ветку `main` сайт автоматически собирается и публикуется. Нужно один раз
включить Pages в **Settings → Pages → Source → GitHub Actions**.
